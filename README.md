# ⛽ Wemos D1 Mini — Tankpreis & Digital Clock

[![Platform: ESP8266](https://img.shields.io/badge/Platform-ESP8266-orange.svg)](https://en.wikipedia.org/wiki/ESP8266)
[![Framework: Arduino](https://img.shields.io/badge/Framework-Arduino-blue.svg)](https://www.arduino.cc/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![API: Tankerkoenig](https://img.shields.io/badge/API-Tankerk%C3%B6nig-yellow.svg)](https://creativecommons.tankerkoenig.de/)

Умный настольный информер цен на топливо и цифровые часы на базе микроконтроллера **Wemos D1 Mini (ESP8266)** и 4-разрядного 7-сегментного LED-индикатора **TM1637**. 

Проект в реальном времени получает актуальные цены на бензин и дизель в Германии через официальный API **Tankerkönig** (creativecommons.tankerkoenig.de), чередует их с точными часами по NTP, плавно регулирует яркость, анимирует тип топлива и предоставляет адаптивный мобильный веб-интерфейс для настройки.

## 🌟 Основные возможности

### 🕒 Часы и отображение
- **NTP-синхронизация времени**: Автоматическая синхронизация с серверами точного времени (`pool.ntp.org`, `time.google.com`), автоматический переход на летнее/зимнее время (часовой пояс Берлина/Германии `CET/CEST`).
- **Мигающее двоеточие**: Секундное двоеточие в центре дисплея (`:`).
- **Чередование режимов и поддержка нескольких фаворитов**: Можно выбрать сразу несколько станций и сортов топлива (например, одновременно Дизель и E5). Дисплей последовательно показывает:
  - Точные часы с мигающим двоеточием (например, 20 сек).
  - Бегущую строку с сортом первого топлива (`dIESEL`) → цена (например, 10 сек).
  - Бегущую строку со вторым топливом (`bEnZIn E5`) → цена (например, 10 сек).
  - Возврат к часам.
- **Плавное затухание (Fade In / Fade Out)**: Мягкий переход яркости при смене экранов без резких скачков.
- **Индикация тренда цены**: При изменении цены перед её показом дисплей кратковременно отображает `UP` (цена выросла) или `dn` (цена упала).
- **Индикация закрытия заправки**: Если заправка временно закрыта, вместо цены выводится `CLOS`.
- **Минутная бегущая строка**: Если выбран только один сорт топлива, анимация названия плавно пробегает раз в минуту; если выбрано несколько — перед каждым переключением на соответствующую цену.
- **Ночной режим (Night Mode)**: Настраиваемый интервал (например, с 23:00 до 07:00) с пониженной яркостью или полным отключением дисплея (`0` = выключен).

### 🏷️ Настраиваемые форматы цены
В веб-интерфейсе можно выбрать один из 4 форматов отображения цены на 4-значном индикаторе:
1. `4-stellig exakt`: Полные 4 цифры без разделителя (например, `2379` для 2.379 €).
2. `Gerundet mit Unterstrich`: Округление до сотых с нижним подчёркиванием (например, `2_38`).
3. `Gerundet mit Mittelstrich`: Округление до сотых со средним дефисом (например, `2-38`).
4. `Gerundet ohne Strich`: Округление до сотых с пустым знакоместом (например, `2 38`).

### 📶 Multi-WiFi менеджер и сеть
- **Хранение до 5 Wi-Fi сетей**: Устройство помнит несколько точек доступа (дом, работа, мобильная раздача) и при включении автоматически подключается к лучшей доступной.
- **Ручное добавление сетей**: Можно вбить SSID и пароль заранее в веб-интерфейсе, даже если сети сейчас нет поблизости.
- **Последовательный вывод IP-адреса**: При успешном подключении к сети дисплей поочерёдно показывает заставку `IP  `, а затем каждый из 4 октетов (например, `192 ` → `168 ` → `178 ` → ` 45 `).
- **Captive Portal**: Если сохранённых сетей нет или они недоступны, Wemos поднимает точку доступа `Tankpreis-Setup` со страницей быстрой настройки.

### 📱 Адаптивный веб-интерфейс
- Полностью оптимизирован под экраны смартфонов (iOS и Android) и десктопы.
- **Поиск заправок**:
  - По немецкому почтовому индексу (**PLZ**) с радиусом в км.
  - По GPS-координатам (**Широта / Долгота**) или авто-определению «📍 Mein Standort».
  - По прямому **UUID** станции из базы Tankerkönig.
- **Мульти-избранное**: Сохранение до 10 заправок с возможностью включать/выключать любые из них в ротацию с помощью переключателей `[✅ Aktiv (im Wechsel)]` / `[▶ Aktivieren]`. В шапке сразу отображаются карточки всех активных цен.
- **Управление системой**: Кнопки быстрой перезагрузки (**Neustart**) и полного сброса настроек (**Reset** к заводским настройкам) с форматированием LittleFS.

## 🛠️ Аппаратное подключение (Pinout)

Для сборки требуется микроконтроллер **Wemos D1 Mini** (ESP8266) и 4-разрядный LED-дисплей **TM1637**:

| TM1637 Дисплей | Wemos D1 Mini Pin | ESP8266 GPIO | Примечание |
| :--- | :--- | :--- | :--- |
| **CLK** | **D3** | GPIO0 | Тактовый сигнал дисплея |
| **DIO** | **D4** | GPIO2 | Сигнал данных дисплея |
| **VCC** | **5V** (или 3V3) | 5V / 3.3V | Питание дисплея |
| **GND** | **GND** | GND | Общий провод |

```
    +-------------------+
    |   Wemos D1 Mini   |
    |                   |
    |         D3 (GPIO0)--------> CLK [ TM1637 ]
    |         D4 (GPIO2)--------> DIO [ Дисплей ]
    |                5V --------> VCC
    |               GND --------> GND
    +-------------------+
```

> ℹ️ *Примечание*: Анимация при поиске сети бегает по внешнему периметру дисплея (верхние, боковые и нижние сегменты всех 4 цифр).

## 💻 Сборка и прошивка

### Вариант 1: PlatformIO (VS Code)
Проект содержит готовый файл [`platformio.ini`](platformio.ini). Для сборки и прошивки достаточно одной команды:
```bash
pio run -t upload
```

### Вариант 2: Arduino IDE
1. Установите пакет плат **ESP8266** (v3.1.2 или новее) в Boards Manager.
2. Установите библиотеки через Library Manager:
   - `TM1637Display` by Avishay Orpaz
   - `ArduinoJson` by Benoît Blanchon (v7.x)
3. Настройки платы:
   - **Board**: `LOLIN(WEMOS) D1 R2 & mini` (или `Generic ESP8266 Module`)
   - **Flash Size**: `4MB (FS:2MB OTA:~1019KB)`
   - **CPU Frequency**: `80 MHz` (или `160 MHz`)
   - **Upload Speed**: `460800` или `921600`

### Вариант 3: Прошивка через командную строку (esptool)
```powershell
# Компиляция
arduino_debug.exe --verify --board esp8266:esp8266:d1_mini --pref build.path="$env:TEMP\Tankpreis_build" Wemos-Tankpreis.ino

# Загрузка прошивки
esptool.py --chip esp8266 --port COM7 --baud 460800 write_flash 0x0 "$env:TEMP\Tankpreis_build\Wemos-Tankpreis.ino.bin"
```

## 🚀 Первый запуск и настройка

1. При первом включении Wemos создаст открытую Wi-Fi сеть: **`Tankpreis-Setup`**.
2. Подключитесь к этой сети со смартфона или ноутбука — откроется страница настройки (или перейдите в браузере по адресу `http://192.168.4.1/`).
3. **Вкладка WiFi**: Выберите домашнюю сеть или введите SSID/пароль вручную и нажмите **Verbinden**.
4. После подключения дисплей покажет полученный IP-адрес (например, `192` → `168` → `178` → `45`). Откройте этот IP в браузере.
5. **Вкладка API**: Вставьте бесплатный API-ключ от [creativecommons.tankerkoenig.de](https://creativecommons.tankerkoenig.de).
6. **Вкладка Suche**: Найдите нужную заправку по PLZ (почтовому индексу) и добавьте желаемый сорт топлива в избранное.
7. **Вкладка Setup**: Настройте интервалы переключения времени и цены, ночной режим и желаемый формат цены (`2379`, `2_38`, `2-38` или `2 38`).
